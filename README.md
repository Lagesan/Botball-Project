### *本组接线，仅供参考*
在 Botball (Wombat 控制器) 的编程环境中，主要使用的是 C 语言的 `<kipr/wombat.h>` 函数库。针对你们目前正在安装新外设（如传感器、舵机、电机等）的需求，我从教材中提取了所有核心的外设控制与读取**函数（方法）**，并按照外设类别为你总结成了下表：

### Botball-PRE 核心外设编程方法总结表

所有程序开头均需要引入头文件：`#include <kipr/wombat.h>`

| 外设类别 | 方法/函数名 | 参数说明 | 功能描述 |
| :--- | :--- | :--- | :--- |
| **基础系统控制** | `msleep(time)` | `time`: 毫秒数 (1秒=1000毫秒) | 延迟/等待指定时间。常用于让电机转动一定时间或等待舵机运动到位。 |
| **直流马达 (Motor)**<br/>*(用于底盘驱动)* | `motor(port, speed)` | `port`: 端口号 (通常为0或1)<br>`speed`: 速度 (-100 到 100) | 驱动指定端口的马达。正数前进，负数后退，0为停止。 |
| | `ao()` | 无参数 | 停止所有马达转动 (All Off)。 |
| **马达编码器/码盘**<br/>*(用于精准移动)* | `clear_motor_position_counter(port)` | `port`: 马达端口号 | 清零指定马达的角度传感器（码盘）数值，准备开始新的测距。 |
| | `get_motor_position_counter(port)` | `port`: 马达端口号 | 读取指定马达当前的码盘数值。马达旋转一圈反馈数值为 1800。 |
| **舵机 (Servo)**<br/>*(用于机械臂/爪/升降)*| `enable_servo(port)` / `enable_servos()` | `port`: 舵机端口号 (0-3)<br>无参数则开启所有 | 开启指定舵机或所有舵机供电，舵机会锁定在当前位置。 |
| | `disable_servo(port)` / `disable_servos()` | `port`: 舵机端口号 (0-3)<br>无参数则关闭所有 | 关闭指定舵机或所有舵机供电，手可以自由转动舵机。 |
| | `set_servo_position(port, position)` | `port`: 舵机端口号<br>`position`: 位置参数 (0-2047) | 设定舵机旋转到指定绝对位置。1024通常为中位。**注意：调用后需配合 `msleep()` 给予舵机转动时间。** |
| **模拟传感器 (Analog)**<br/>*(红外/灰度/光线)* | `analog(port)` | `port`: 模拟端口号 (Analog 0-5) | 读取模拟传感器的反馈值，**范围是 0 - 4095**。<br>• **红外**：数值越大离障碍物越近。<br>• **灰度**：数值随黑白深浅变化。<br>• **光线**：数值随环境明暗变化。 |
| **数字传感器 (Digital)**<br/>*(触碰开关)* | `digital(port)` | `port`: 数字端口号 (Digital 0-9) | 读取数字传感器的反馈值。本质是布尔型变量：<br>• **0**: 松开状态 (逻辑假)<br>• **1**: 按下状态 (逻辑真) |

| **按键调试** | `c_button_clicked()` | 无参数 | 监听控制器**触摸屏幕**上的 "C" 按钮是否被点击，常配合 `while(!c_button_clicked());` 用于分段调试。 |

### 💡 备赛与调试建议 (基于教程扩展)：

1. **加装新传感器时必须做“阈值”测试：**
   * 无论是红外测距（检测易拉罐）还是灰度循线，装好外设后，**不要直接写代码**。
   * 先在 Wombat 控制器主界面的 `Sensor List` 中查看实时数值。
   * 记录下“有障碍”和“无障碍”（或“黑线”和“白底”）的数值，求**平均数**作为代码中的判断阈值 (offset)。
2. **保护新装的舵机 (非常重要！)：**
   * 教程中特别警告：编写 `set_servo_position` 时，**千万不要让舵机转到被物理结构卡死的位置**。一旦堵转，舵机内的小电机会迅速过热烧毁。在写代码前，先用手掰动记录下安全的 `position` 范围。
3. **善用自定义函数优化代码：**
   * 当你们的底盘和外设定型后，建议把底盘的前进、后退、转弯，以及机械爪的张开、闭合，封装成自定义函数（如 `runByPc(speed, distance)` 或 `claw_open()`），这会让你们在比赛现场修改路线时事半功倍，极大减少由于代码太长导致的逻辑错误。
